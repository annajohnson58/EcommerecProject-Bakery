# E‑Commerce Bakery Website (MERN Stack)

## Overview
Freshly baked goods deserve a modern storefront. This project is a full‑stack e‑commerce platform built with the MERN stack (MongoDB, Express.js, React, Node.js), designed to bring a bakery’s warmth and flavor into the digital world. Customers can browse products, customize orders, and enjoy a seamless checkout experience — while admins manage inventory, track sales, and keep the oven running smoothly.

---

## Features
- Beautiful Product Catalog: Browse breads, cakes, pastries, and seasonal specials with images, descriptions, and prices.
- Shopping Cart & Checkout: Add items to cart, adjust quantities, and complete purchases with secure payment integration.
- User Accounts: Customers can register, log in, and track their orders. Admins have role‑based access to manage products and orders.
- Order Management: Real‑time order tracking for customers; dashboard for admins to update status and manage fulfillment.
- Responsive Design: Optimized for desktop, tablet, and mobile.
